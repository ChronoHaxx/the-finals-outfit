## Remaining sequence

1. **Expand compatible families in batches.** Reuse the recovered ordinary accessory shaders and component frames; inspect missing Medium meshes and their complete default material slots. In the original 44-choice accessory cohort, 28 are enabled and 16 remain deferred. Close compatible ordinary cases first; carry masked/emissive cases into their shared shader work.
2. **Scale clothing through shared shader families.** Complete new mesh/material bindings for already supported shader variants, then extend the common layered and eight-layer shader permutations. The 9 September reference audit found their union on 2,029 choices (70.8%); that is an overlapping candidate population, not a forecast that one fix completes 2,029 items. Missing secondary parts, default slots and fitting can still block a complete choice.
3. **Complete the remaining material and composition systems.** Cover glass, transparency, emissive and animated effects, displays, remaining nails, hair/face variants and cosmetic layering. Group by actual shader requirements and source metadata; item-specific tuning is reserved for exceptions supported by evidence.
4. **Validate usable Medium outfits.** Expand source rules for body/hair culling, sleeves, wrists, headwear, attachment fit and interacting cosmetic layers. Check representative outfit combinations, swaps, removal and reload. Fix confirmed purple issues and expand multi-angle review. These checks run during each batch too; this stage closes broader interaction gaps before counting the 80% target as accepted.
5. **Finish catalog coverage and other bodies.** Resolve remaining exceptions, add Light/Heavy and the supported body-type fits, then improve motion, lighting, stability, loading and memory use. Keep an explicit remaining-issue list and final user acceptance separate from automated passes.

At least 2,293 choices must pass the agreed usable-Medium acceptance criteria to reach 80%. Current touched coverage is not that acceptance measure. Future percentage and timing claims require measured batch pass rates; the infrastructure should allow many choices per shared fix, but does not guarantee a one-week finish.

Automated and agent acceptance is distinct from the pending guided human checks before PR merge.
